# Offline Hindi → Mundari AI Teaching Assistant (SIH 2026 PS 26042)

An offline, edge-capable AI Teaching Assistant designed for mother tongue-based primary education in Mundari, targeting low-cost Android devices (~2GB RAM).

---

## 🏛️ Architectural Overview & Pipeline

The system operates strictly offline on-device without cloud API dependencies:

```
[Teacher Hindi Speech]
       │
       ▼
[Android Mic / Audio Capture]
       │
       ▼
[Audio Preprocessing + VAD]
       │
       ▼
[Offline Hindi ASR (Whisper Tiny / whisper.cpp)]
       │
       ▼
[Hindi Text Normalization]
       │
       ▼
[Hindi → Mundari NMT (IndicTrans2 Backbone + LoRA Adaptation)]
       │
       ▼
[Linguistic Verification Engine (Lexicon + FLN Vocabulary + Phrase Memory + Scorer)]
       │
       ▼
[Verified Mundari Text]
       │
       ▼
[Mundari TTS (Meta MMS facebook/mms-tts-unr VITS)]
       │
       ▼
[Android Speaker Output]
```

## 🔄 Phase 3 Workflow: Tokenizer Inspection & Data Prep

Run tokenization inspection on Hindi and Mundari diagnostic fixtures:
```bash
python -m translation.tokenizer_inspect
```

Prepare canonical Phase 2 records for IndicTrans2 fine-tuning:
```bash
python -m translation.prepare_data --train-file data/processed/train.jsonl --validation-file data/processed/validation.jsonl --test-file data/processed/test.jsonl --output-dir data/indictrans_prep
```

Training preparation accepts explicit dataset paths, so a future filtered
synthetic corpus can replace only the training input while the original
validation/test reference files remain protected. No synthetic data is
generated by this repository at the current stage.

Evaluate translation predictions using SacreBLEU:
```bash
python -m translation.evaluate --hypotheses predictions.txt --references references.txt
```
